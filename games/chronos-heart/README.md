# Сердце Хроноса

Головоломка в духе The Room: стимпанк-мастерская пропавшего часовщика, шкатулка с секретами и круглый люк, который нужно оживить.

Один файл `index.html`, без сборки и зависимостей: открыть в браузере (на телефоне тоже). Графика — векторный SVG, звук синтезируется через Web Audio, прогресс сохраняется в `localStorage`.

Цепочка загадок: письмо → картина → настенные часы → шестерня в шкатулке → книжный шкаф → красная линза → кольца-шифр → паровой контур → люк.
