# Осень-88

Уютный пиксельный квест про советскую осень 1988 года. Суббота, Осенний бал в ДК «Юность» — нужно записать Лене кассету: сторона А — Modern Talking, сторона Б — «Кино».

Открыть: `index.html` в любом браузере. Всё в одном файле — графика рисуется кодом, музыка синтезируется через Web Audio, прогресс сохраняется в браузере.

- 5 локаций: комната, двор, гаражи, проспект, актовый зал ДК
- день сменяется вечером по мере прохождения
- мини-игры: перемотка кассеты карандашом, «Ну, погоди!», танец на дискотеке
- 4 необязательных секрета

Управление: мышь или палец; пробел — дальше; Esc — убрать вещь из рук; M — звук.
